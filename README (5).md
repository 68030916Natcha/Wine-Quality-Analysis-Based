| :--- | :--- | :--- | :--- | :---: |
| `type` | ข้อความ (`object`) | `white`, `red` | ประเภทของไวน์ | 0 |
| `fixed acidity` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณกรดคงที่ (เช่น กรดทาร์ทาริก) | 0 |
| `volatile acidity` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณกรดระเหยง่าย (เช่น กรดอะซิติก) | 0 |
| `citric acid` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณกรดซิตริก (ช่วยเพิ่มความสดชื่น) | 0 |
| `residual sugar` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณน้ำตาลตกค้างหลังการหมัก | 0 |
| `chlorides` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณเกลือ (โซเดียมคลอไรด์) | 0 |
| `free sulfur dioxide` | ตัวเลข (`float64`) | $mg/dm^3$ | ปริมาณซัลเฟอร์ไดออกไซด์อิสระ (ต้านการเจริญของจุลินทรีย์) | 0 |
| `total sulfur dioxide` | ตัวเลข (`float64`) | $mg/dm^3$ | ปริมาณซัลเฟอร์ไดออกไซด์รวมทั้งหมด | 0 |
| `density` | ตัวเลข (`float64`) | $g/cm^3$ | ความหนาแน่นของไวน์ | 0 |

| `sulphates` | ตัวเลข (`float64`) | $g/dm^3$ | ปริมาณซัลเฟต (สารต้านอนุมูลอิสระและแบคทีเรีย) | 0 |
| `alcohol` | ตัวเลข (`float64`) | % vol | เปอร์เซ็นต์ระดับแอลกอฮอล์ | 0 |
| `quality` | ตัวเลข (`int64`) | คะแนน 3 ถึง 9 | คะแนนคุณภาพไวน์ประเมินโดยผู้เชี่ยวชาญ | 0 |

## 3. การทำความสะอาดข้อมูลและการปรับแต่งตัวแปร (Data Cleaning & Feature Engineering)

### 3.1 การจัดการข้อมูลซ้ำซ้อน (Duplicate Removal)
* **ผลการตรวจสอบ:** พบข้อมูลซ้ำกันทุกคอลัมน์จำนวน **1,177 แถว**
* **การจัดการ:** ดำเนินการลบแถวซ้ำออกคงเหลือข้อมูลคุณภาพจำนวน **5,320 แถว** แบ่งเป็น:
  * **ไวน์ขาว (White Wine):** 3,961 แถว (74.46%)
  * **ไวน์แดง (Red Wine):** 1,359 แถว (25.54%)

### 3.2 การสร้างตัวแปรใหม่ (Feature Engineering)
ได้ทำการวิศวกรรมฟีเจอร์เพิ่ม 3 ตัวแปรเพื่อเพิ่มมิติในการวิเคราะห์:

1. **`bound_sulfur_dioxide`** $= \text{total sulfur dioxide} - \text{free sulfur dioxide}$
   * วัดปริมาณซัลเฟอร์ไดออกไซด์ที่จับตัวกับสารอื่นในไวน์
2. **`sugar_acid_ratio`** $= \frac{\text{residual sugar}}{\text{fixed acidity}}$
   * วัดดัชนีสมดุลความหวานและความเปรี้ยว
3. **`quality_group`** (การจัดกลุ่มระดับคุณภาพ):
   * `Low`: คะแนน 3 - 4
   * `Medium`: คะแนน 5 - 6
   * `High`: คะแนน 7 - 9

### 4.2 การวิเคราะห์ความสัมพันธ์กับคุณภาพไวน์ (Correlation with Quality)

จากการคำนวณค่าสัมประสิทธิ์สหสัมพันธ์เพียร์สัน (Pearson's $r$) ระหว่างตัวแปรทางเคมีกับคะแนนคุณภาพ (`quality`):

* **ปัจจัยส่งผลบวกต่อคุณภาพ (Positive Factors):**
  1. `alcohol` ($r = +0.469$): แอลกอฮอล์สูงสัมพันธ์กับคุณภาพที่สูงขึ้นอย่างชัดเจน
  2. `citric acid` ($r = +0.098$): กรดซิตริกช่วยเพิ่มความสดชื่น
* **ปัจจัยส่งผลลบต่อคุณภาพ (Negative Factors):**
  1. `density` ($r = -0.326$): ความหนาแน่นที่สูงสัมพันธ์กับคุณภาพที่ต่ำลง
  2. `volatile acidity` ($r = -0.265$): กรดระเหยที่มากเกินไปสร้างกลิ่นกรดอะซิติก/น้ำส้มสายชู ทำให้คุณภาพแย่ลง
  3. `chlorides` ($r = -0.202$): ปริมาณเกลือที่สูงเกินไปส่งผลเสียต่อรสชาติ

## 5. สรุปข้อเสนอแนะเชิงวิเคราะห์ (Key Insights)

1. **ปัจจัยหลักในการควบคุมคุณภาพ:** การควบคุมระดับแอลกอฮอล์ให้เหมาะสม และการลดกรดระเหยง่าย (`volatile acidity`) รวมถึงความหนาแน่น มีความสำคัญอย่างยิ่งต่อการปรับปรุงคะแนนคุณภาพไวน์
2. **ความแตกต่างตามประเภทไวน์:** การวิเคราะห์หรือการสร้างโมเดลทำนายคุณภาพ (Machine Learning) ควรแยกโมเดลระหว่างไวน์แดงและไวน์ขาว หรือใช้ตัวแปร `type` เป็นฟีเจอร์หลัก เนื่องจากคุณสมบัติทางเคมีพื้นฐานมีความแตกต่างกันอย่างสิ้นเชิง
